# IoT-Based Smart Car Parking System

An IoT-based smart parking system using ESP32, IR sensors, Blynk, and I2C LCD to monitor parking slot availability in real time.

## Components
- ESP32
- 4 IR Sensors
- I2C LCD
- Blynk IoT Platform

## Features
- Real-time parking slot detection
- LCD display for slot status
- Blynk-based monitoring
- Automatic detection using IR sensors
